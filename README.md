# Community Service Platform

Protótipo fictício para organizar solicitações de uma iniciativa comunitária. O exemplo demonstra levantamento de requisitos, categorização, comunicação de status e cuidado com dados pessoais.

## Funcionalidades

- Lista de solicitações inteiramente fictícias.
- Filtros por situação.
- Formulário local de demonstração; novos itens existem apenas durante a sessão do navegador.

## Conteúdos relacionados

Atividade de Extensão, Projeto de Aplicação de GTI, Sistemas de Informação, comunicação e ética.

## Executar

Abra `index.html` em um navegador. Nenhum dado é enviado ou salvo. Não foram usados documentos, nomes, demandas ou dados reais de projetos de extensão.
